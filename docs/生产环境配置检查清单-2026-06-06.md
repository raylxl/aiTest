## 1. 环境变量配置

### 1.1 必需环境变量

| 变量名 | 说明 | 示例值 | 配置位置 |
|--------|------|--------|----------|
| `DATABASE_URL` | Neon PostgreSQL 连接字符串 | `postgresql://user:pass@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require` | Vercel 环境变量 |
| `AI_API_KEY` | AI API 密钥（服务端使用） | `sk-xxx` | Vercel 环境变量 |
| `NEXT_PUBLIC_AI_API_KEY` | AI API 密钥（前端可访问） | `sk-xxx` | Vercel 环境变量 |

### 1.2 可选环境变量

| 变量名 | 说明 | 默认值 | 备注 |
|--------|------|--------|------|
| `AI_BASE_URL` | AI API 基础 URL | `https://api.deepseek.com` | 如使用其他 AI 服务需配置 |
| `AI_MODEL` | AI 模型名称 | `deepseek-chat` | 可选模型：deepseek-chat, gpt-4 等 |

## 2. 数据库配置检查

### 2.1 Neon PostgreSQL 配置

- [ ] 数据库已创建
- [ ] 连接字符串格式正确（包含 `?sslmode=require`）
- [ ] 数据库用户有足够权限（CREATE TABLE, INSERT, UPDATE, DELETE, SELECT）
- [ ] 数据库区域与 Vercel 部署区域相近（减少延迟）

### 2.2 数据库表结构

系统会在首次运行时自动创建以下表：

1. **fee_types** - 费用类型表
2. **fee_rules** - 费用规则表
3. **waybills** - 运单表
4. **template_mappings** - 模板映射表
5. **import_batches** - 导入批次表
6. **import_orders** - 导入运单表
7. **parse_rules** - 解析规则表
8. **upload_sessions** - 上传会话表（新增）
9. **upload_chunks** - 上传分片表（新增）
10. **schema_migrations** - 数据库迁移记录表

### 2.3 数据库迁移

系统使用自动迁移机制：
- 冷启动时自动执行 `initDB()` 函数
- 迁移记录存储在 `schema_migrations` 表中
- 支持增量迁移，不会重复执行已完成的迁移

## 4. Vercel 部署配置

### 4.1 项目设置

- [ ] 项目已连接到 GitHub 仓库
- [ ] 构建命令：`npm run build`
- [ ] 输出目录：`.next`
- [ ] Node.js 版本：18.x 或更高

### 4.2 环境变量配置

在 Vercel 项目设置中配置环境变量：

1. 进入项目设置 → Environment Variables
2. 添加以下变量：
   - `DATABASE_URL`
   - `AI_API_KEY`
   - `NEXT_PUBLIC_AI_API_KEY`
3. 选择应用环境（Production, Preview, Development）

### 4.3 部署区域

建议选择与数据库相近的区域：
- 如数据库在 `us-east-2`，Vercel 部署区域也选择 `us-east-2`
- 可在 Vercel 项目设置 → Functions → Region 中配置

## 6. 常见问题排查

### 6.1 数据库连接问题

**问题：** `Error: DATABASE_URL is not configured`

**解决方案：**
1. 检查 Vercel 环境变量是否配置 `DATABASE_URL`
2. 确认连接字符串格式正确
3. 检查数据库用户权限

### 6.2 AI API 调用失败

**问题：** `AI API key is required` 或 API 调用超时

**解决方案：**
1. 检查 `AI_API_KEY` 环境变量是否配置
2. 确认 API 账户有足够额度
3. 检查网络连接是否正常

### 6.3 文件上传失败

**问题：** 大文件上传失败或超时

**解决方案：**
1. 检查文件大小是否超过 Vercel 限制（默认 4.5MB）
2. 确认分片上传功能正常工作
3. 检查数据库连接是否稳定

### 6.4 解析规则生成失败

**问题：** AI 无法生成有效的解析规则

**解决方案：**
1. 检查 AI API 是否正常工作
2. 确认上传的文件格式正确
3. 检查文件内容是否包含有效数据
